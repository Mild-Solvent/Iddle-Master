Two buttons

One takes the clutter. One takes everything.

Nothing is disabled, only stopped — a reboot puts the machine back on its own.

BOOST NOW

Kill the clutter, keep working

Updaters, launcher services, tray webviews, the search indexer — the processes nobody opened on purpose. Frees roughly 1.5–2 GB.

Survives: your desktop, your browser, everything you opened yourself — and anything with a window on screen.
ABSOLUTE IDLE

Strip it to Windows vitals

Browsers, chat apps, the shell itself. Lands the whole machine around 1.5–2 GB in use — kernel, Defender, and your remote access.

Survives: Sunshine, Tailscale, Defender, networking. Nothing else.
Restore desktop puts back exactly what the last run took away — each run writes the list of what it stopped, and Restore walks it backwards.

The sentry

Killing 2 GB once is easy.

Twenty minutes later WebView2 has respawned for a tray icon, WSearch trigger-started itself, and Razer's launcher is back. A background thread re-applies the same lists on a timer, so RAM stays where you put it.

It asks before killing anything you started

On its first sweep it takes a census. Everything running then is the junk the mode was aimed at. Anything that appears after is something you deliberately started — so it gets a toast instead of a bullet.

  • Keep it — left alone 30 minutes, then asked again.
  • Always keep — written into [protect], remembered forever.
  • Trash it — closed now, and silently from then on.

No answer in 25 seconds counts as keep it. The tool should never be the reason you lost work while you were away from the keyboard.

Two brakes

  • Respawn backoff — if one name comes back six times, it stops fighting for 30 minutes. An endless kill/respawn loop costs more CPU than the process ever cost you in RAM.
  • Open windows are sacred — during boost, a process whose parent chain owns a visible window is never touched. Close the window and the leftovers are reclaimed as usual.

The safety story

Most of the code is about not stranding you.

This kills processes on a machine you can only reach remotely. That fact shapes everything.

Protected list wins over everything

[protect] is checked before any kill, even if something is also on a kill list. Sunshine, tailscaled, Defender, lsass, the audio stack, the NVIDIA display container, Docker and its WSL backend — containers you left running matter more than the RAM the backend costs.

Network guard

Before finishing, it verifies Sunshine and Tailscale are running, that something is listening on a Sunshine port, and that the Tailscale adapter is up. If a service died as collateral damage it restarts it and says so loudly.

Everything is reversible

Services are stopped, never disabled, so a reboot returns the machine to normal on its own. Restore disarms the sentry first — otherwise it would shoot everything Restore just brought back.

The one scary part. Absolute idle closes explorer.exe — your taskbar and wallpaper disappear. If you stream in to a blank screen: Ctrl+Shift+Esc → File → Run new task → browse to IdleMaster.exe → Restore desktop. Task Manager is handled by winlogon, so it works with no shell running. Or set KillExplorer=0 and idle mode leaves the desktop alone.

Command line

Everything the window does, scriptable.

IdleMaster.exe 
IdleMaster.exe               open the window
IdleMaster.exe --boost       boost mode, no UI
IdleMaster.exe --idle        absolute idle, no UI
IdleMaster.exe --restore     undo (also stops the sentry)
IdleMaster.exe --report      print what's eating RAM, and the plan
IdleMaster.exe --boost --watch   boost, then keep hunting
IdleMaster.exe --watch       take up the watch for the last mode
IdleMaster.exe --unwatch     stop the sentry
IdleMaster.exe --installtask run the sentry at every logon

Install

Run IdleMasterSetup.exe. It installs to %LOCALAPPDATA%\Programs\IdleMaster — your own profile, so no administrator is needed (the app elevates itself when it runs, which is where admin is actually needed). Start Menu shortcut, normal entry in Installed apps, optional logon task.

Updating is the same file, and Check for updates in the window does it for you — a portable copy updates itself where it stands. Nothing downloads until you say yes. Your idlemaster.ini is never overwritten.

Build it yourself

Compiles with the .NET Framework compiler that already ships inside Windows. No SDK, no NuGet, no internet.
